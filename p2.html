PRACTICAL 02

Digital Evidence Acquisition Using FTK Imager

Aim

To create a forensic disk image using FTK Imager and verify data integrity using MD5 and SHA-1 hash values.

Steps

  1. Select the Source Type

    Open FTK Imager and select File → Create Disk Image. Choose Physical Drive to acquire the entire drive or Logical Drive to acquire a specific volume.

  2. Select the Source Drive

    Select the required drive from the list and click Finish.

  3. Add Image Destination

    In the Create Image window, enable Verify images after they are created and click Add. Select the image format, such as E01 or Raw (dd).

  4. Enter Evidence Details

    Enter the case number, evidence number, examiner details, destination folder, and image filename. Set the fragment size if required, then click Finish.

  5. Start Image Acquisition

    Review the settings and click Start to begin creating the forensic image.

  6. Monitor Acquisition and Verification

    Wait for the imaging process and automatic verification to complete.

  7. Verify Hash Values

    Check the Image Verification Results window and confirm that the source and image hash values match. Note any reported errors or bad sectors.

  8. Review the Acquisition Log

    Open the generated text log file, if available, to review the acquisition details, timestamps, and hash values.
