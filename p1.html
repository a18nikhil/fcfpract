PRACTICAL 01

Aim

To install and set up digital forensic tools such as FTK Imager, Autopsy, and Wireshark for acquiring, analyzing, and investigating digital evidence.

Steps

  1. Download the Tools

    Visit the official websites of FTK Imager, Autopsy, and Wireshark and download their installers.

  2. Install FTK Imager

    Run the FTK Imager installer and follow the installation instructions to complete the setup.

  3. Install Autopsy

    Run the Autopsy installer, follow the setup instructions, and install any required components.

  4. Install Wireshark

    Run the Wireshark installer and install the required packet-capture component, such as Npcap on Windows.

  5. Launch the Tools

    Open each application and verify that it starts successfully without errors.

  6. Verify the Setup

    Check that FTK Imager can access its imaging functions, Autopsy allows case creation, and Wireshark displays the available network interfaces.

  7. Complete the Setup

    Confirm that all three tools are installed and ready for their respective forensic tasks.

Result

FTK Imager, Autopsy, and Wireshark are installed and configured for their respective digital forensic tasks.
