PRACTICAL 03

Aim

To perform digital forensic investigation using Autopsy by analyzing a disk image and examining digital evidence.

Steps

  1. Create a New Case

    Open Autopsy and select Create New Case.

  2. Enter Case Details

    Enter the case name, storage directory, case number, and examiner details. Click Finish.

  3. Select Data Source

    Select Disk Image or VM File and click Next.

  4. Add Disk Image

    Browse and select the disk image file. Set the appropriate time zone if required.

  5. Select Ingest Modules

    Select modules such as Recent Activity, File Type Identification, Keyword Search, and Hash Lookup. Click Finish to begin processing.

  6. Analyze Digital Evidence

    Wait for processing to complete. Examine the file system, deleted files, browser history, downloads, and other available artifacts.

  7. Examine File Details

    Select relevant files to view their properties, timestamps, file sizes, and content.

  8. Generate Forensic Report

    Use the available reporting options to generate a forensic report, if required.
